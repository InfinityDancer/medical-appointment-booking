# Medical Appointment Booking

Text (WhatsApp) and Live Voice Agents support to aid medical appointment booking. This repository contains my work at Prognos Labs.

## Project Structure (Branches)

This repository is organized into different branches, each containing specific features and components of the system:

- **`text_agent`** (or **`main`**): Contains the core `medisync` text application (via WhatsApp).
- **`voice-agent`**: Contains the live telephonic voice agent integration (`medisync-TELEcmi-integration`).
- **`medisync_ARAG`**: Feature Agentic RAG added to the WhatsApp (text) agent for medical appointment booking.
- **`medisync_whatsapp_workflows`**: Contains specialized WhatsApp workflows added as a feature to the text agent.
