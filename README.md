# medical-appointment-booking
Text (WhatsApp) and Live Voice Agents support to aid medical appointment booking.

My work at Prognos Labs

This repository contains 4 branches:
- `main_app` contains the code for the text agent accessible to users via WhatsApp.
- `voice-agent` entails the Live Telephonic Voice Agent integration for the Medical Appointment Booking system. The voice agent is designed to handle medical appointment bookings, general inquiries, and patient assistance over live voice calls.
- `Agetnic-RAG` contains the Agentic Retrieval-Augmented Generation (RAG) feature for the Medical Appointment Booking system's (text agent).
- `whatsapp-workflows` contains specialized WhatsApp Workflows
